Full-duplex transfer: write write while reading into read, byte-paced through the TX/RX FIFOs (zero-padded TX / discarded RX for the shorter slice).

Source

pub unsafe fn register_block(&self) -> &'static RegisterBlock

Borrow the underlying PAC register block for this SPI instance.

§Safety

This bypasses the typed SPI driver. The caller must uphold all PAC aliasing, ordering, and peripheral-state invariants.

§Stability

This API is marked as unstable and is only available when the unstable crate feature is enabled. This comes with no stability guarantees, and could be changed or removed at any time.

Source

pub fn wait_idle(&self) -> Result<(), SpiError>

Wait for all pending TX data to be transmitted and the SPI bus to become idle.

Source

pub fn with_dma(self, dma: DmaDriver<'d, Dma0>) -> SpiDma<'d, T>

Consume the blocking SPI driver + a DMA driver, returning a DMA-capable SpiDma. The blocking Spi API is no longer accessible (esp-hal style — blocking and DMA surfaces are mutually exclusive, a compile-time guarantee).

§Stability

This API is marked as unstable and is only available when the unstable crate feature is enabled. This comes with no stability guarantees, and could be changed or removed at any time.
