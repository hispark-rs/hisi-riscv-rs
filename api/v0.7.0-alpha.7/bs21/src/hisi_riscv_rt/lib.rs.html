1//! # hisi-riscv-rt
2//!
3//! Runtime entry support for HiSilicon RISC-V firmware.
4//!
5//! The public crate interface is intentionally small: it re-exports the
6//! `riscv-rt` entry attributes, the selected chip PAC's interrupt enum, and the
7//! single-hart critical-section implementation configured through the `riscv`
8//! crate. Chip-specific reset code, linker fragments, and image headers live
9//! behind startup adapters.
10//!
11//! Current adapters:
12//! - `chip-ws63`: WS63 startup, linker layout, interrupt symbols, and optional
13//!   link-time boot header.
14//! - `chip-bs21` + `unstable`: BS2X compatibility path.
15//!
16//! Downstream binaries should link with `-Thisi-riscv-link.x`.
17//!
18//! # Architecture overview
19//!
20//! ```text
21//! Power-on / reset
22//!   │
23//!   ▼
24//! reset_vector (asm/ws63/startup.S)
25//!   ├── Clear PMP, set mtvec, disable interrupts
26//!   ├── Enable FPU, initialize gp / sp
27//!   ├── Fill stack canary
28//!   └── tail runtime_init
29//!         │
30//!         ▼
31//!       runtime_init() (Rust, chips/ws63/startup.rs)
32//!         ├── Shared-RAM init (dyn_mem_cfg)
33//!         ├── Cache init & invalidate
34//!         ├── Multi-region relocation (ROM data, TCM text/data, SRAM text/data)
35//!         ├── BSS zeroing
36//!         ├── ROM patch enable
37//!         ├── MIE bits set (TIMER0-2, RTC, I2C0, I2C1)
38//!         └── call main()
39//!               │
40//!               ▼
41//!             your #[entry] fn main() -> !
42//! ```
43//!
44//! ```text
45//! Interrupt arrives
46//!   │
47//!   ▼
48//! mtvec → trap_vector (vectored mode)
49//!   ├── mie_interruptX_handler / local_interrupt_handler
50//!   │     ├── csrci mstatus, 0x08          (disable interrupts)
51//!   │     ├── hisi_push_task_context       (save 272B unified frame)
52//!   │     ├── csrw mscratch, sp            (stash frame pointer)
53//!   │     ├── la sp, __irq_stack_top__     (switch to IRQ stack)
54//!   │     ├── call user_handler            (weak symbol override)
55//!   │     ├── csrr a0, mscratch            (a0 = frame)
56//!   │     ├── call __hisi_irq_epilogue     (RTOS scheduling hook)
57//!   │     ├── j __hisi_resume_trap         (restore frame + mret)
58//!   │
59//!   ├── trap_entry (exceptions)
60//!   │     ├── save_all                     (save 36-word frame incl. CSRs)
61//!   │     ├── csrw mscratch, sp
62//!   │     ├── la sp, __exc_stack_top__
63//!   │     ├── dispatch via excp_vect_table
64//!   │     ├── csrr sp, mscratch
65//!   │     ├── restore_all + mret
66//!   │
67//!   └── nmi_vector
68//!         ├── csrci mstatus, 0x08
69//!         ├── save_all
70//!         ├── csrw mscratch, sp
71//!         ├── la sp, __nmi_stack_top__
72//!         ├── call nmi_handler
73//!         ├── csrr sp, mscratch
74//!         ├── restore_all + mret
75//! ```
76//!
77//! # Quick start
78//!
79//! ```rust,ignore
80//! #![no_std]
81//! #![no_main]
82//!
83//! use hisi_riscv_rt::entry;
84//!
85//! #[entry]
86//! fn main() -> ! {
87//!     // At this point:
88//!     //   - .data / .bss / TCM sections have been relocated
89//!     //   - FPU is enabled (mstatus.FS = Dirty)
90//!     //   - L1 caches are initialized and invalidated
91//!     //   - MIE bits are set
92//!     //   - ROM patch table is resident in ITCM
93//!     //   - ITCM / DTCM are available
94//!     //   - WiFi / BT protocol stacks are NOT yet initialized
95//!     loop {}
96//! }
97//! ```

99//! # Interrupt handling
100//!
101//! ## Weak-symbol override convention
102//!
103//! Interrupt handlers in `startup.S` are declared as **weak symbols** (`.weak`
104//! directive). To handle an interrupt, define a function with the **exact same
105//! name** in your Rust code:
106//!
107//! ```rust,ignore
108//! #[unsafe(no_mangle)]
109//! extern "C" fn TIMER_INT0() {
110//!     // your ISR logic — no register save/restore, no mret
111//! }
112//! ```
113//!
114//! The handler is called by the assembly entry with the following environment
115//! already set up:
116//!
117//! - A 272-byte unified `TaskContext` frame has been saved via
118//!   `hisi_push_task_context`.
119//! - `sp` points to the **IRQ stack** (`__irq_stack_top__`).
120//! - Machine interrupts are disabled; the entry will re-enable them on exit.
121//! - `mscratch` holds the saved frame pointer (see below).
122//!
123//! Your handler **must** follow these rules:
124//!
125//! - **Signature**: `extern "C" fn()` — no arguments, no return value.
126//! - **No `mret`**: the assembly entry performs `mret` via `__hisi_resume_trap`.
127//! - **No direct `mscratch` access**: `mscratch` is owned by the runtime.
128//! - **Do not block** or wait on hardware indefinitely — the interrupt entry
129//!   masks interrupts, and the epilogue expects a timely return.
130//! - **If two modules define the same weak symbol**, the linker silently picks
131//!   one — there is no duplicate-symbol error.
132//!
133//! ## `mscratch` register contract
134//!
135//! The `mscratch` CSR is **exclusively owned** by `hisi-riscv-rt`. It is used to
136//! atomically swap the stack pointer between execution contexts via `csrrw`:
137//!
138//! ```text
139//! Normal execution:   mscratch = __irq_stack_top__
140//! During interrupt:   mscratch = saved TaskContext frame pointer
141//! During exception:    mscratch = saved frame pointer (36-word save_all)
142//! During NMI:         mscratch = saved frame pointer
143//! ```
144//!
145//! **User code must never read or write `mscratch`.** Doing so silently corrupts
146//! the stack-switch machinery and will cause undefined behaviour on the next
147//! trap.
148//!
149//! ## Four-stack model
150//!
151//! The runtime allocates four independent stacks in SRAM (top-down, sizes
152//! configurable via `memory.x`):
153//!
154//! | Stack | Symbol | Default size | Used by |
155//! |---|---|---|---|
156//! | User / main | `__stack_top__` | 8 KiB | application code |
157//! | IRQ | `__irq_stack_top__` | 2 KiB | MIE interrupts (26-31) and local interrupts (32-91) |
158//! | Exception | `__exc_stack_top__` | 2 KiB | synchronous exceptions (illegal insn, bus fault, …) |
159//! | NMI | `__nmi_stack_top__` | 1 KiB | non-maskable interrupt |
160//!
161//! Each stack is independent — an overflow in one does not corrupt the others.
162//! Stack sizes can be overridden in your `memory.x`:
163//!
164//! ```ld
165//! __irq_stack_size = 0x1000;  /* 4 KiB */
166//! ```
167//!
168//! # RTOS integration
169//!
170//! When an RTOS (e.g. `hisi-rtos`) is linked, it provides a **strong symbol**
171//! for `__hisi_irq_epilogue`:
172//!
173//! ```rust,ignore
174//! #[unsafe(no_mangle)]
175//! extern "C" fn __hisi_irq_epilogue(frame: usize) -> usize {
176//!     // frame: *mut TaskContext (272-byte unified frame on IRQ stack)
177//!     // return: *mut TaskContext (same or different task's frame)
178//! }
179//! ```
180//!
181//! The epilogue may select a different task's frame to resume. If no RTOS is
182//! linked, the default weak symbol returns `frame` unchanged (resume the
183//! interrupted context).
184//!
185//! # Feature flags
186//!
187//! | Feature | Default | Chip | Effect |
188//! |---|---|---|---|
189//! | `bundled-memory-x` | on | all | Emit default `memory.x` via `build.rs` |
190//! | `chip-ws63` | off | WS63 | WS63 startup adapter, `ws63-pac/rt` interrupts |
191//! | `chip-bs21` | off | BS2X | BS2X startup adapter (requires `unstable`) |
192//! | `boot-header` | off | WS63 | Embed 0x300-byte HiSilicon image header at `0x230000` |
193//! | `ws63-bgle-32k` | off | WS63 | Use 32 KiB BGLE exchange memory profile (radio images) |
194//! | `ws63-radio-main-stack-32k` | off | WS63 | Select the HIL-verified 32 KiB main-stack envelope for synchronous radio bootstrap |
195//! | `startup-uart-trace` | off | WS63 | Emit 4-char markers (e.g. `RT2!`) on UART0 during startup |
196//! | `riscv-rt-start-experiment` | off | WS63 | Delegate `_start` to `riscv-rt`; inject WS63 hooks (requires `unstable`) |
197//! | `unstable` | off | all | Gate for experimental APIs (no stability guarantee) |
198//!
199//! # Safety invariants
200//!
201//! Users of this crate must uphold these contracts:
202//!
203//! - **`mscratch` exclusivity**: do not read or write `mscratch` in any
204//!   application, HAL, or RTOS code.
205//! - **Weak-symbol signature**: handlers must be `extern "C" fn()` with no
206//!   arguments and no return value. Mismatched signatures cause UB.
207//! - **No duplicate weak symbols**: if two translation units define the same
208//!   handler name, the linker silently picks one — there is no error.
209//! - **Stack sizing**: ensure each stack is large enough for its worst-case
210//!   depth. The runtime does not perform stack overflow checking.
211//! - **Chip-specific addresses are in chip adapter docs**: see the
212//!   `chips::ws63` or `chips::bs2x` source modules for memory maps and startup
213//!   sequences.
214//!
215//! # Linker conventions
216//!
217//! When `bundled-memory-x` is enabled (default), `hisi-riscv-rt` emits
218//! `memory.x` via `build.rs`. If you provide a custom `memory.x`:
219//!
220//! - The four stack symbols (`__stack_top__`, `__irq_stack_top__`,
221//!   `__exc_stack_top__`, `__nmi_stack_top__`) must be defined in the `.stacks`
222//!   section of `layout.ld` in the correct relative order.
223//! - `.text.entry` and `.text.runtime.init` must be placed at the start of the
224//!   PROGRAM region.
225//! - ITCM/DTCM ORIGIN values must match the target chip (see chip adapter docs).
226//! - The `PRESERVE` region (256 bytes at end of SRAM) must not be removed —
227//!   boot state is shared through it.
