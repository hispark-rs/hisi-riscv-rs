1//! WS63 startup adapter.
2//!
3//! # Startup paths
4//!
5//! Default path (`chip-ws63` without `riscv-rt-start-experiment`):
6//!   asm/ws63/startup.S → runtime_init() (Rust) → main()
7//!
8//! Experimental path (`chip-ws63` + `riscv-rt-start-experiment`):
9//!   riscv-rt _start → __pre_init (stack canary) → .data/.bss/FPU →
10//!   _setup_interrupts → runtime_init_riscvrt (ROM/TCM/SRAM reloc, MIE) →
11//!   mtvec set → j main
12//!
13//! # WS63 memory map
14//!
15//! | Region | Start | Size | Purpose |
16//! |---|---|---|---|
17//! | BOOTROM | `0x100000` | 36 KiB | Mask ROM boot |
18//! | ROM | `0x109000` | 268 KiB | Application ROM (SFC, pinmux, WDT, timer, TCXO, BT, WiFi) |
19//! | ITCM | `0x14C000` | 16–64 KiB | Instruction TCM (patch tables, ROM veneers, hot code) |
20//! | DTCM | `0x180000` | 16–64 KiB | Data TCM (ROM data, TCM data/BSS) |
21//! | FLASH | `0x200000` | 8 MiB | External SPI NOR flash (XIP) |
22//! | PROGRAM | `0x230300` | ~2.75 MiB | Application code in flash |
23//! | SRAM | `0xA00000` | 512–576 KiB | Main system RAM (code, data, stacks, heap) |
24//!
25//! The ITCM contains:
26//! - `.patch` — ROM function patch redirection table
27//! - `.rom_ram_cb` — ROM→RAM callback veneers
28//! - `.text_tcm` / `.rodata.tcm` — user hot code/data
29//!
30//! The DTCM contains:
31//! - `.rom_data` / `.rom_bss` — ROM runtime state
32//! - `.data_tcm` / `.bss_tcm` — user hot data
33//!
34//! # WS63 interrupt map
35//!
36//! | IRQ | Name | Tier | Mechanism |
37//! |---|---|---|---|
38//! | 26 | TIMER_INT0 | MIE | Standard `mie` bit 26 |
39//! | 27 | TIMER_INT1 | MIE | Standard `mie` bit 27 |
40//! | 28 | TIMER_INT2 | MIE | Standard `mie` bit 28 |
41//! | 29 | RTC_IRQ | MIE | Standard `mie` bit 29 |
42//! | 30 | (gap) | — | — |
43//! | 31 | I2C0_INT | MIE | Standard `mie` bit 31 |
44//! | 32 | I2C1_INT | LOCAL | Custom `LOCIEN0` |
45//! | 33 | GPIO_INT0 | LOCAL | Custom `LOCIEN0` |
46//! | 34 | GPIO_INT1 | LOCAL | Custom `LOCIEN0` |
47//! | 35 | GPIO_INT2 | LOCAL | Custom `LOCIEN0` |
48//! | 36 | SOFT_INT0 | LOCAL | Custom `LOCIEN0` |
49//! | 37 | SOFT_INT1 | LOCAL | Custom `LOCIEN0` |
50//! | 38 | SOFT_INT2 | LOCAL | Custom `LOCIEN0` |
51//! | 39 | SOFT_INT3 | LOCAL | Custom `LOCIEN0` |
52//! | 40 | COEX_WL_INT | LOCAL | Custom `LOCIEN0` |
53//! | 41 | COEX_BT_INT | LOCAL | Custom `LOCIEN0` |
54//! | 42-91 | … | LOCAL | Custom `LOCIEN0-2` |
55//!
56//! MIE interrupts (26–31) are gated by the standard RISC-V `mie` CSR.
57//! Local interrupts (32+) are gated by HiSilicon custom `LOCIEN0-2` CSRs
58//! (`0xBE0-0xBE2`) with priority fields in `LOCIPRI0-15` (`0xBC0-0xBCF`).
59//!
60//! # Feature flags
61//!
62//! | Feature | Effect |
63//! |---|---|
64//! | `boot-header` | Embed 0x300-byte HiSilicon image header at `0x230000`; run `hisi-fwpkg patch-hash` post-link to fill the body SHA-256 |
65//! | `ws63-bgle-32k` | Use 32 KiB BGLE exchange memory (RAM9); required for Wi-Fi/BLE combo images built from `ws63-liteos-app` blob |
66//! | `startup-uart-trace` | Emit 4-character markers (e.g. `RT2!`, `RD0!`) on UART0 during startup |
67//!
68//! # `runtime_init` sequence
69//!
70//! The default startup adapter (`asm/ws63/startup.S`) calls `runtime_init()`
71//! (in [`startup`]) before jumping to the user's `#[entry] fn main()`.
72//! The sequence is:
73//!
74//! 1. `__hisi_ws63_shared_ram_init()` — configure ITCM/DTCM bank assignment
75//! 2. `__hisi_ws63_cache_init()` — invalidate and enable L1 caches
76//! 3. `relocate_data()` — copy initialized sections from flash to
77//!    ITCM/DTCM/SRAM. Regions: ROM patch, ROM data, WiFi ROM data,
78//!    TCM text, TCM data, SRAM text, `.data`.
79//! 4. Clear caller-owned shared arenas before enabling D-cache, then
80//!    `zero_bss()` clears ROM BSS, TCM BSS, and SRAM BSS
81//! 5. `__hisi_ws63_rom_patch_enable()` — enable the ROM patch controller
82//!    (only if the patch table in ITCM is non-empty)
83//! 6. Re-enable machine interrupts (`csrs mie, 0x888` — TIMER0-2, RTC,
84//!    I2C0, I2C1)
85//! 7. `call main()`
