impl<'d> Rtc<'d>

Source

pub fn new(_rtc: RtcPeriph<'d>, load: u32, mode: Mode) -> Self

Start the RTC counting from load in mode (hal_rtc_v150_config_load + _start). For a free-running counter use Mode::FreeRun.

typed-config exemption: load is written verbatim into the 32-bit load_count0 register (the low half of the 64-bit counter), so every u32 is a valid, runnable value — nothing to truncate or clamp. (The board-crystal precondition is documented at the module level.)

Source

pub fn read_count(&self) -> u64

Read the live 64-bit counter using the cnt_req → cnt_lock coherent-read handshake (hal_rtc_v150_get_current_value).

Source

True if the timer interrupt is pending (raw_intr bit0).
