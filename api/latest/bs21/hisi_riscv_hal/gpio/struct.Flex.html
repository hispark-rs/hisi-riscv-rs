Source

pub fn is_high(&self) -> bool

Read the pin level as an input: temporarily switch to input, sample, then restore the previous output-enable state.

Source

pub fn is_low(&self) -> bool

Returns true if the pin reads low (see is_high).

Source

pub fn set_as_output(&mut self)

Explicitly set the pad direction to output (clears OEN). Pair this with the data methods to make the direction switch visible instead of relying on the implicit switch inside set_high/set_low/toggle.

Source

pub fn set_as_input(&mut self)

Explicitly set the pad direction to input / high-Z (sets OEN). Pair this with is_high to sample without the implicit save/restore.

Source

pub fn number(&self) -> u8

Returns this pin’s number (0-18).

Source

pub fn degrade(self) -> AnyPin<'d>

Type-erase this Flex pin back to an AnyPin (consumes the driver). Safe: the pad keeps its current direction/level; only the typed wrapper is dropped.
