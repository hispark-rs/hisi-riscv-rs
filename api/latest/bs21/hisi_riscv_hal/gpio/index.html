Module gpio 

Source
Expand description

GPIO drivers: type-erased AnyPin, typed Input/Output/Flex. GPIO driver for WS63 (19 pins: GPIO0 bits 7-0, GPIO1 bits 15-8, GPIO2 bits 18-16).

Three GPIO blocks at 0x4402_8000, 0x4402_9000, 0x4402_A000.

§Pin drivers

  • [Input] — digital input with configurable pull
  • [Output] — push-pull output
  • [Flex] — combined input + output driver
  • [AnyPin] — type-erased pin
