I2C peripheral clock (= TCXO_HZ, 24 MHz).

Unlike UART/SPI, the I2C clock is not switched to the PLL: clock_init sets it to the TCXO crystal via i2c_port_set_clock_value(REQ_24M) (fbb_ws63 clock_init.c), and the SCL divisor math (SCL = clock / (2*(scl_h+scl_l)*2)) is computed against this value. (ch2’s nominal “I2C = 80 MHz” is the bus-capability figure, not the divisor base the SDK uses.)
