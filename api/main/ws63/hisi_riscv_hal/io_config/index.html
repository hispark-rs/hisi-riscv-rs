Pin mux / pad I/O configuration helpers. IO Configuration (Pin Mux and Pad Control) driver for WS63.

The WS63 IO_CONFIG peripheral controls pin function selection (muxing) and pad characteristics (drive strength, pull resistors, Schmitt trigger, input enable) for all GPIO, UART, and SFC pads.

§Pin mux

Each GPIO pin can be assigned one of several functions via a 3-bit mux select register. The exact function mapping depends on the chip configuration.

§Pad control

Each pad has independent control over:

  • Drive strength (3-bit, 000 = strongest, 111 = weakest)
  • Pull resistor (none, pull-up, pull-down)
  • Schmitt trigger (enable/disable)
  • Input enable (enable/disable)
