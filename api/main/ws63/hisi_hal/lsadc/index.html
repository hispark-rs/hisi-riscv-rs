Low-speed ADC (v154) driver. Low-Speed ADC (LSADC) driver for WS63 — v154 controller.

Register map and bit fields are cross-checked against the WS63 C SDK (hal_adc_v154_regs_def.h, hal_adc_v154_regs_op.{c,h}, hal_adc_v154.c). The control bank is the contiguous adc_regs_t struct at base 0x4400_C000:

RegisterOffsetPurpose
LSADC_CTRL_00x00scan config: per-channel enable + sample timing
LSADC_CTRL_10x04FIFO status (rne/rff/bsy) + waterline
LSADC_CTRL_20x08interrupt mask/status
LSADC_CTRL_80x1Cscan start/stop
LSADC_CTRL_90x20FIFO read data (data[13:0], channel[16:14])
LSADC_CTRL_110x24analog enable (da_lsadc_en) + reset (rstn@16)
CFG_DATA_SEL0xDCdata output select
CFG_OFFSET0xE0offset correction
CFG_GAIN0xE4gain correction
CFG_CIC_FILTER_EN0xE8CIC filter enable
CFG_CIC_OSR0xECCIC oversampling ratio

§Status

Not validated on silicon. The full analog power-up sequence (the SDK’s hal_adc_simulation_cfg magic writes to da_lsadc_en and the da_lsadc_rwreg registers, plus offset/cap/gain calibration) is not implemented here; [LsAdc::set_analog_enable] exposes da_lsadc_en for callers that port it.
