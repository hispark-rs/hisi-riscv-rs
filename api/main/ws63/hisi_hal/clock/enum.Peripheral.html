pub fn cken_info(&self) -> Option<(u8, u8)>

The CLDO_CRG clock-gate register index (0 = CKEN_CTL0, 1 = CKEN_CTL1) and bit position for this peripheral.

The CLDO_CRG clock-gate register index (0 = CKEN_CTL0, 1 = CKEN_CTL1) and bit position for this peripheral, or None if the SDK does not individually gate it (it relies on the reset-default clock; no bit is attested by the SVD or porting code).

PWM occupies 9 contiguous gates (CKEN_CTL0 bits 2..=10); this returns its base bit (2). I2S returns its clk gate (bit 12); it also has a bus gate at bit 11. See the module docs for the provenance of each.
