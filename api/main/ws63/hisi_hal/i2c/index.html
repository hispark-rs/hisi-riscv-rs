Module i2c

Expand description

I2C driver (WS63 custom v150 core). I2C master driver for WS63 (I2C0/1, FIFO-capable).

SCL = I2C_CLK / (2 * (scl_h + scl_l) * 2) where each scl value*2 = actual period. The I2C clock is the 24 MHz TCXO crystal (crate::soc::chip::I2C_CLOCK_HZ), NOT the 240 MHz CPU clock: unlike UART/SPI, the vendor clock_init leaves I2C on the crystal (i2c_port_set_clock_value(REQ_24M)).
