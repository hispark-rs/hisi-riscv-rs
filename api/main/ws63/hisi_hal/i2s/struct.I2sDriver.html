Expand description

I2S audio interface driver, parameterised by clock role (Master or the currently unstable Slave).

impl<'d> I2sDriver<'d, Master>

Source

pub fn new_master(i2s: I2s<'d>, config: &MasterConfig) -> Self

Create and fully configure an I2S master. Self-enables the I2S clock tree, programs the framing/width/FIFO registers, and derives + programs the BCLK/FS dividers from (data_width, channels).

Source§

impl<'d> I2sDriver<'d, Slave>

Source

pub fn new_slave(i2s: I2s<'d>, config: &SlaveConfig) -> Self

Create and fully configure an I2S slave (BCLK/FS supplied externally; no dividers). Self-enables the bus clock so the FIFOs/registers are reachable.
