Enum ClockEdge 

Source 
pub enum ClockEdge {
    Rising,
    Falling,
}
Expand description

Clock edge selection (mode register bit 6). Meaningful for a slave; a master drives the vendor-default falling edge.

§Stability

This API is marked as unstable and is only available when the unstable crate feature is enabled. This comes with no stability guarantees, and could be changed or removed at any time.
