Struct TimerAlarm0

pub struct TimerAlarm0<'d> { /* private fields */ }
Expand description

Exclusive owner of TIMER0 as an interrupt-driven one-shot alarm.

This unstable token is intended for executors and schedulers. It cannot be constructed alongside another TimerDriver because both consume the singleton Timer peripheral.

§Stability

This API is marked as unstable and is only available when the unstable crate feature is enabled. This comes with no stability guarantees, and could be changed or removed at any time.
