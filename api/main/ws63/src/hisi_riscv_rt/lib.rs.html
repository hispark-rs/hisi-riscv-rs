1//! # hisi-riscv-rt
2//!
3//! Runtime entry support for HiSilicon RISC-V firmware.
4//!
5//! The public crate interface is intentionally small: it re-exports the
6//! `riscv-rt` entry attributes, the selected chip PAC's interrupt enum, and the
7//! single-hart critical-section implementation configured through the `riscv`
8//! crate. Chip-specific reset code, linker fragments, and image headers live
9//! behind startup adapters. Chip interrupt symbols (`device.x`) are owned by the
10//! selected PAC's `rt` feature.
11//!
12//! Current adapters:
13//! - `chip-ws63`: WS63 startup, linker layout, `ws63-pac/rt` interrupt symbols,
14//!   and optional link-time boot header.
15//! - `chip-bs21` + `unstable`: BS2X compatibility path. This crate provides a
16//!   BS21/BS2X default `memory.x`, a BS2X layout adapter, legacy startup, and
17//!   `bs2x-pac/rt` provides `device.x`. BS20/custom boards should provide their
18//!   own `memory.x`.
19//!
20//! Downstream binaries should link with `-Thisi-riscv-link.x`.
21

63// ---- Experimental path: riscv-rt _start + WS63 overrides ----
64// When riscv-rt-start-experiment is enabled, we defer to riscv-rt's _start
65// (which handles GPR zero, GP/SP, .data/.bss, FPU) and provide:
66//   - __pre_init: WS63 stack canary
67//   - _setup_interrupts: WS63 mtvec + MIE bits
68//   - trap_vector + all trap/IRQ handlers (WS63 direct-mode dispatch)
69// The ROM/TCM/SRAM multi-region relocation is still handled by runtime_init,
70// called from __pre_init via our Rust startup adapter.
71// When riscv-rt-start-experiment is enabled, all WS63 startup assembly
72// (__pre_init, _setup_interrupts, trap_vector, default handlers) is compiled
73// via build.rs+cc into a separate .o to avoid LTO symbol conflicts with
74// riscv-rt's weak defaults. See asm/ws63/startup_riscvrt.S.
75
76#[cfg(all(feature = "chip-bs21", not(feature = "riscv-rt-start-experiment")))]
77core::arch::global_asm!(concat!(
78    ".set __hisi_chip_bs2x, 1\n",
79    include_str!("../asm/ws63/task_context.S"),
80    include_str!("../asm/ws63/startup.S")
81));
