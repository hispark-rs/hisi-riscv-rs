Struct Pdm

pub struct Pdm<'d> { /* private fields */ }
Expand description

PDM-microphone audio front-end driver (BS2X IP v150): decimates the DMIC PDM bitstream into PCM words drained from the UP FIFO.

pub fn new(_p: PdmPeriph<'d>) -> Self

Bring up the full DMIC-CH0 audio path (CIC + SRC + UP FIFO) and start it (hal_pdm_v150_set_attr + _start).

Source

pub fn version(&self) -> u32

Read the PDM IP version register (presence/bring-up check).

Source

pub fn capture(&self, buf: &mut [u32]) -> usize

Capture PCM samples from the UP FIFO into buf (CPU-polled). Each entry is a 32-bit FIFO word (the meaningful PCM is the upper 16 bits). Returns the number of samples actually captured (fewer than buf.len() only on timeout).
