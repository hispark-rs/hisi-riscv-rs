BS2X PDM microphone audio front-end (v150) driver. BS2X PDM — PDM-microphone audio front-end (IP v150).

BS2X-only (chip-bs21); no WS63 analogue. The PDM block decimates a PDM mic bitstream (CIC + compensation + sample-rate conversion) into 32-bit PCM words that queue in the UP FIFO. The FIFO is a fixed (non-incrementing) MMIO data window at 0x5208_E080 — the vendor drains it by DMA, but it is also directly CPU-readable, gated on the UP-FIFO status (up_fifo_st @ 0x30, bit2 = empty). Register map + sequence from fbb_bs2x hal_pdm_v150; bs2x-pac Pdm @ 0x5208_e000 models the config registers, status register, and FIFO data window.
