Ultra-low-power GPIO driver (GPIO v150 block). Ultra-Low-Power GPIO (ULP_GPIO) driver for WS63.

The WS63 ULP_GPIO provides 8 additional GPIO pins (GPIO107-114) that can operate in ultra-low-power modes. The register layout is identical to the standard GPIO blocks.

These pins are accessible at physical address 0x5703_0000 and use the same register layout as GPIO0.
