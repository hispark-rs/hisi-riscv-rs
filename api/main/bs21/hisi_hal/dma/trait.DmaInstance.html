Required Associated Constants§

const CHANNEL_BASE: u8

Logical channel number of this controller’s first physical channel.

MDMA exposes logical channels CHANNEL_BASE..CHANNEL_BASE+4 (0-3); SDMA exposes 8-11. The driver subtracts this base to index the controller’s physical channels 0-3 — see the module-level “Channel addressing” docs.

fn bypass_auto_clock_gate()

Bypass auto clock-gating for this controller, if needed.

The WS63 M_DMA clock is auto-gated when the controller is idle; the primary controller must set this bit so its clock keeps running across a transfer, otherwise a started transfer never advances (its done bit never sets). Mirrors the vendor dma_port_register_irq() “BYPASS dma自动门控” (DMA_CLK_AUTO_CTRL_REG |= DMA_CLK_ON_MASK).
