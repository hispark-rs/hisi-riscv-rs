Returns true if the counter was successfully refreshed. Callers should check this after reading before relying on the counter value.

Source

pub fn read_counter(&self) -> Option<u64>

Read the full 64-bit counter value.

Triggers a refresh to latch the current value, then reads all four 16-bit count registers. Returns None if the refresh timed out.

Source

pub fn read_counter32(&self) -> Option<u32>

Read the lower 32 bits of the counter (faster, triggers refresh).

Returns None if the refresh timed out.
