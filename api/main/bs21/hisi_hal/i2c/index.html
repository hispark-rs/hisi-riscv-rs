Module i2c

Expand description

I2C driver (BS2X Synopsys DesignWare v151 core). BS2X I2C master driver — DesignWare SSI core (IP version v151).

BS2X’s I2C is a Synopsys/DesignWare ic_* controller, a COMPLETELY different IP from WS63’s custom v150 I2C (i2c.rs). This module is the BS2X (chip-bs21) implementation of the i2c module; lib.rs picks it per chip. The register map and the master transaction sequences are from the fbb_bs2x hal_i2c_v151 driver (sole ground truth); the v151 register block was rewritten into bs2x-pac (BS2X.svd) for this.

API mirrors i2c.rs: I2c::new_i2c0/1, write, read, write_read, plus a probe (ACK detection) for bus scans.
