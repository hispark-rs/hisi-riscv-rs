Module peripherals 

Source
Expand description

Peripheral singleton tokens and the Peripherals struct (take()/steal()). Peripheral singletons wrapping the WS63 PAC.

Each peripheral is a zero-sized type that grants safe, exclusive access to the underlying hardware registers. The Peripherals struct is obtained once via Peripherals::take().
