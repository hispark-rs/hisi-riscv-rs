Struct BaudRate 

Source 
pub struct BaudRate(/* private fields */);
Expand description

A validated UART baud rate. The 16-bit integer divider is div = UART_CLOCK_HZ / (16 · baud), so against the default 160 MHz PLL base the realisable baud is [~153, 10 000 000]. try_new rejects anything outside that instead of the old silent low-clamp (baud < min_baud → min_baud). Note: a UartClock::Boot (the 24/40 MHz flashboot console clock) shifts the realisable range down — keep boot-console firmware at ordinary baud rates such as 115200.
