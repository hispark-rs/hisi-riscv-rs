BS2X key-matrix scanner (HID) driver. BS2X KEYSCAN — key-matrix scanner (IP v150).

BS2X-only (chip-bs21); no WS63 analogue. Scans a row/column key matrix and reports pressed/released keys through a FIFO. Register map from fbb_bs2x hal_keyscan_v150; bs2x-pac’s keyscan block is a faithful match.

Blocking model: new() configures + starts the scanner; read_key() polls the event status and pops one decoded key from key_value_fifo (row/col/pressed).
