# WS63 RF A1 Allocator Migration - 2026-07-13

## Scope

This evidence records the first A1 ownership extraction: allocation mechanics
move from `ws63-rf-rs` into the independent `hisi-alloc` release unit. It does
not mark A1 complete; ROM, crypto, radio-sys and link ownership remain in the
transitional RF crate.

## Boundary

- `hisi-alloc` owns caller-provided arenas, alignment, zeroing, ownership-header
  validation, deallocation and reallocation mechanics.
- The WS63 RF adapter owns `osal_kmalloc`/`osal_kfree`, linker arena selection
  and RF diagnostics.
- The generic allocator contains no chip address, linker symbol, vendor ABI or
  Wi-Fi policy.
- The 16-byte ownership header is preserved so the migration does not change
  the RF heap footprint relative to the frozen A0 implementation.

## Silicon Parity

Board: WS63 EVB. The WPA2-Personal credential was injected through the build
environment and is intentionally absent from this evidence.

```text
RF1_IMAGE_OK
RF2_INIT_BEGIN
RF3_SCAN_OK count=0x00000017
RF5B_WPA_CONNECT_OK freq=0x0000096c
RF5A_DHCP_OK addr=192.168.155.2
RF5A_ARP_OK rx=0x00000004
RF5C_PING_OK rx=0x00000005
```

The image was packaged through the canonical `hisi-fwpkg` path, transferred by
`hisiflash` with an explicit loaderboot at 115200 baud, and booted by a physical
J-Link reset. The final ICMP marker proves that allocator extraction preserved
the complete Rust-visible connectivity path, not only startup or scan.
