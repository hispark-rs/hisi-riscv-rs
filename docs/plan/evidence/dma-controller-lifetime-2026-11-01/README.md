# DMA 控制器生命周期编译对照

本批只收紧实验性 guard 的控制器生命周期，不修改寄存器和运行时流程。
三个启动入口的 compile-fail/正例由 HAL 子仓文档测试维护；本目录保存父仓外
远端依赖消费者的最小源码、独立锁文件及精简报告。

`positive/` 应通过主机和 RISC-V check，`negative/` 应因 E0521/E0499 失败。
在各自目录执行 report.json 中的命令。两工程均有独立 `[workspace]`，没有
绝对路径依赖；显式固定未发布 runtime 开发覆盖，不能作为 registry 发布验收。
旧 HAL 接受反例，新 HAL 拒绝；该反例证明控制器重新取得的生命周期漏洞，
没有执行 DMA，也不单独证明已发生缓冲区 UAF。

三芯片主机/目标检查以及旧芯片文档测试通过；BS20 的锁文件问题单列。
原始日志保存在 report.json 指定位置并记录校验值。未运行 QEMU 或操作实板。
正常完成的总线排空、缓存及高层 DMA 契约仍未关闭，不能称整个 DMA 已安全。
