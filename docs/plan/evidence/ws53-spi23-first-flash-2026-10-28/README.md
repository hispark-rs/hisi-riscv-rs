# WS53 SPI23 首轮 Flash 失败与恢复

烧录前双构建一致、同ELF QEMU四场景、147项记录/AP0拒绝及Clippy通过。hisiflash完成当前4MiB备份、七页更新和整片回读；Flash只输出BEGIN，没有完成SPI测试。

SPI内层记录停在读取GPIO方向前，CPU位于默认异常入口0x45e310，AP0读取GPIO1 0x57028000失败。首次诊断失败后CPU仍暂停，另行物理复位用于恢复准备；随后CSR观察还处于等待路径，未捕获原始mepc，不能宣称精确故障指令已确认。

SDK应用明确在使用GPIO1前设置0x57030024.bit0，现有Rust交接缺少此初始化，模型也未覆盖关门场景。隔离RDL/PAC已补描述和测试，尚未集成GPIO驱动或新模型；没有通过主机临时打开时钟掩盖失败，物理因果仍需受控验证。

已用原页精确恢复测试前4MiB和本轮NV，整片回读、原厂AT及1800次SWD/CPU检查通过。原厂只读观察为时钟半字/整字均1、GPIO1方向0xff7，可访问。此次Flash功能验收为失败、合格SPI帧为零；不改写正常QEMU结果或既有RAM证据。原始厂商内容和物理采样私有保留。
