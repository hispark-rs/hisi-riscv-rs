# WS63 RF A0 Baseline - 2026-07-12

## Scope

This is the migration parity fixture after RF5C. It records the compact,
reviewable evidence needed by A1-A4 without committing multi-megabyte generated
maps or vendor logs. The implementation baseline is parent `3a2cccd5` plus
`ws63-examples c05d294` and `hisi-riscv-hal c918e82`.

## Silicon Markers

Board: WS63 EVB. Network: open `HUAWEI-HLJ_Guest`. Target: `1.1.1.1`.

```text
RF2_INIT_OK ifname=wlan0 netif=0x00a325d0 drv_send=0x00280054 hwlen=0x00000006 mac=0024a5f001c5
RF5B_CONNECT_OK freq=0x0000096c
RF5A_DHCP_OK addr=192.168.155.2 prefix=0x00000018 router=192.168.155.1
RF5A_ARP_OK rx=0x00000003
RF5C_PING_BEGIN target=1.1.1.1 via=192.168.155.1
RF5C_PING_OK rx=0x00000004
```

The RX counter increment from 3 to 4 is the Echo Reply entering the Rust-visible
L2 queue. The defect closed by this run was a 42-byte Ethernet frame whose IPv4
header declared a 60-byte IP packet; the fixed frame is 74 bytes
(14 Ethernet + 20 IPv4 + 8 ICMP + 32 payload), and `total_length` is derived from
the actual frame size.

## Reproduction Contract

1. Build through the guarded two-pass RF script; a plain final `cargo build` is
   not sufficient because it does not prove vendor relocation closure.
2. Generate the image with `hisi-fwpkg plan --chip ws63 --image-output`; do not
   derive header/hash/body ranges in the runner.
3. Download the complete bin with probe-rs at the FlashPlan base address.
4. Pulse physical nRST with J-Link `SetRESET`/`ClrRESET`, capture UART at 115200,
   and require every marker above, especially `RF5C_PING_OK`.
