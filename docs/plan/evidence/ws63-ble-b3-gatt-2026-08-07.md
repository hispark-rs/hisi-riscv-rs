# WS63 BLE B3 GATT Evidence

## Scope

This evidence closes B3: two WS63 boards complete a bounded GATT
client/server lifecycle through the vendor BLE host and the Rust event surface.
The exercised path covers scan, connection, service/characteristic/descriptor
discovery, notification, indication confirmation, and disconnect cleanup. It
does not claim pairing UX, BLE security stability, coexistence, SLE, or a stable
public BLE API.

## Silicon Result

The server and client images were each downloaded once with full verify. All
subsequent samples used only the two J-Link nRST lines and captured both CH340
UART streams. The first complete v55 shape run passed, the fixed-image 3-reset
gate passed 3/3, and the final fixed-image matrix passed 20/20.

The executable contract requires the complete marker sets, including:

```text
RFDBG_BLE_B3_SERVER_CONNECTED
RFDBG_BLE_B3_SCAN_MATCH
RFDBG_BLE_B3_CLIENT_CONNECTED
RFDBG_BLE_B3_SERVICE_FOUND
RFDBG_BLE_B3_CHARACTERISTIC_FOUND
RFDBG_BLE_B3_DESCRIPTOR_FOUND
RFDBG_BLE_B3_NOTIFY_SENT
RFDBG_BLE_B3_NOTIFICATION_OK
RFDBG_BLE_B3_INDICATE_SENT
RFDBG_BLE_B3_INDICATE_CONFIRMED
RFDBG_BLE_B3_INDICATION_OK
RFDBG_BLE_B3_CLIENT_DISCONNECTED
RFDBG_BLE_B3_SERVER_DISCONNECTED
RFDBG_BLE_B3_GATT_OK
```

Every final-matrix record had empty server/client missing-marker lists and an
empty failure-marker list. No run reported a missing ROM callback, bounded-event
drop, command error, discovery error, notification/indication error, or
disconnect error.

The executable evidence contract is
`hil/ws63-ble-gatt-reset-matrix.py`. Raw UART logs and `summary.json` were
captured under `/private/tmp/ws63-ble-b3-20260807-v55/{1reset,3reset,20reset}`
on the HIL host.

## Boundary

This is integration and statistical regression evidence for two fixed images,
two boards, and the stated environment. It validates the B3 callback, bounded
event, and GATT lifecycle paths. It is not a mathematical RTOS proof and does
not prove that RF traffic or future peer implementations can never lose events.
