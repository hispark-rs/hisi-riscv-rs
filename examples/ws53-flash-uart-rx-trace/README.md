# WS53 UART2 Flash RX 与 IRQ 测量标记开发夹具

UART2 AGPIO1/2 未引出，无法直接采集其波形。本夹具保持真实串口七字节收发、
取消和两秒独立期限，在已确认的 MGPIO17 / DSLogic D5 输出 1/2/4ms 前导，
每次真实 UART2 ISR 的进入/退出各一次电平变化，最后输出8ms结束标记。
ISR实际次数允许2至6，须与同一启动UART公布的计数及分析仪脉冲数相等；
QEMU与实板可因字节排队时机而不同，不能用固定IRQ次数替代字节完整性检查。

GPIO17经HAL独占所有权、单hart临界区和静态固定driver存储共享给前台/ISR；
收尾时关闭强输出并恢复pad配置，不宣称恢复厂商程序上下文。MGPIO17仅连分析仪
输入。时钟仍来自限定FlashBoot交接，未证明通用冷态初始化或模拟电气时序。

此夹具尚未实板验收，状态见[实施记录](../../docs/plan/ws53-adaptation.md)。
原无测量标记的UART13 workspace和167项封存证据保持不变。
